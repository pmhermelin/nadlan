# 🏠 Nadlan — מערכת ניהול נדל"ן

מערכת קונסולה בשפת C# לניהול נכסי נדל"ן, פותחה כפרויקט גמר בקורס "ניהול פרויקטים" במכללת אורט הרמלין.

## מטרת הפרויקט

המערכת מדמה פלטפורמה לניהול נדל"ן עבור שלושה סוגי משתמשים — **מנהל**, **סוכן** ו**לקוח** — ומאפשרת ניהול מלא של מחזור החיים של נכס: מהוספתו למערכת, דרך חיפוש וצפייה בו, ועד לתיאום ואישור פגישות צפייה.

הפרויקט פותח תוך יישום מלא של תהליך ניהול פרויקט תוכנה מקצה לקצה: כתיבת דרישות ותכנון טכני, ניהול Backlog ב-Jira, תיעוד ב-Confluence, עבודה מבוזרת בין שני מפתחים תוך שימוש ב-Git Flow (branch לכל Story), ותהליך Code Review מובנה לפני כל מיזוג ל-`master`.

## תכונות עיקריות

- **ניהול משתמשים** — הרשמה, התחברות והתנתקות עם הפרדת הרשאות לפי תפקיד
- **ניהול נכסים** — הוספת נכס, עדכון זמינות, הסרת נכס והצגת נכסי סוכן/סוכנות
- **חיפוש וסינון** — הצגת כל הנכסים הזמינים וחיפוש לפי קריטריונים
- **ניהול פגישות** — שליחת בקשה לפגישת צפייה, אישור פגישה, והצגת פגישות לפי לקוח/נכס/משתמש

## תפקידי משתמש (Roles)

| תפקיד | הרשאות עיקריות |
|---|---|
| מנהל (Manager) | הצגת כלל נכסי הסוכנות |
| סוכן (Agent) | הוספה/הסרה/עדכון נכסים, ניהול פגישות לנכסיו |
| לקוח (Client) | חיפוש נכסים, שליחת בקשות לפגישות צפייה |

## טכנולוגיות

- **שפה:** C# (.NET)
- **ניהול קוד מקור:** Git & GitHub (Feature Branch Workflow)
- **ניהול פרויקט:** Jira (Epic → Story → Sub-task)
- **תיעוד:** Confluence
